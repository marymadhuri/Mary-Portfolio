My Projects

  • 💼 Job Seeker for Low-Income Groups
    A web-based platform designed to connect low-income job seekers with potential employers. The application provides separate login modules for employers and job seekers. Employers can post job vacancies, while job seekers can search and filter jobs based on location, experience, and field. It includes a Naukri-style homepage, intuitive UI, and database management for users and job listings.
    Features:
    • Separate login pages for employers and seekers
    • Job search with filters like location, field, experience
    • Admin dashboard for managing user accounts and listings
    • Responsive homepage with search bar like Naukri.com
    Technologies: Java, JSP, Servlets, JDBC, HTML, CSS, JavaScript, MySQL

  • 🛍️ E-commerce Product Page
    A responsive product page for an online store that displays multiple products with price tags, filtering options, and an add-to-cart system. The project was built during my internship and focuses on providing a seamless shopping experience using clean UI and responsive design principles.
    Features:
    • Product card layout with images, names, and prices
    • Pricing filter and sort functionality
    • Responsive design for all screen sizes
    • Cart icon with dynamic item count (simulated)
    Technologies: HTML, CSS, JavaScript
